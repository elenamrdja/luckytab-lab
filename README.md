# LuckyTab Lab

LuckyTab Lab is a social/commercial experiment around randomized rewards for everyday purchases.

## Sprint goal
Model and prototype mechanisms such as guaranteed discount versus probabilistic large reward, then test whether randomness changes consumer behavior while keeping merchant economics controlled.

## Core learning goals
- Mechanism design
- Experimentation and randomization
- Monte Carlo simulation
- Cohort/behavior analytics
- Merchant economics
- Consumer testing and commercial storytelling

## Definition of done
A configurable prototype lets a merchant define a reward mechanism, simulates expected cost/variance, exposes a consumer experience, and is tested with at least 10 consumers and ideally 2 merchants.

This is a lab experiment, not a real-money gambling product.
